# گزارش آزمون نسخهٔ اولیه

محیط آزمون: Codex Cloud، Linux amd64، Python 3.12، Docker Engine 28.4.0 و Compose v2.40.3. این گزارش، تأیید نصب روی ویندوز واقعی نیست.

## نتیجه‌های تأییدشده

- ۱۵ آزمون خودکار جدید در `tests/test_dashboard.py` گذشت: پروژهٔ چندزبانه، محدودیت اندازهٔ صف، حذف تکراری با شناسه و شناسهٔ جایگزین، ادامهٔ بررسی همان کار موتور، نگهداری ویرایش‌های دستی، فیلتر، خروجی Unicode و محافظت در برابر فرمول، خطای موتور، خروجی خالی، قطع دسترسی، خطای enrichment، محدودیت درخواست محلی، پشتیبان‌گیری و بازیابی و توقف کار بلاتکلیف.
- ۱۱ آزمون قبلی `scripts/test_scrape.py` گذشت؛ کد اصلی اسکرپر و Compose اصلی تغییر نکرده‌اند.
- آزمون مرورگر Chromium با موتور شبیه‌سازی‌شده گذشت: راست‌به‌چپ، ثبت دو کلیدواژه، نمایش پایان کار، یک سرنخ یکتا پس از دو اجرا، ویرایش یادداشت و وضعیت، دانلود CSV/XLSX، نمایش دسکتاپ و موبایل و نبود خطای JavaScript.
- Docker image ساخته شد و دو سرویس داشبورد و موتور healthcheck موفق دارند. رابط از مرورگر واقعی به API داخلی موتور متصل شد.
- برای اتصال داخلی Docker، NO_PROXY فقط برای نام سرویس محلی و loopback تنظیم شد؛ درخواست‌های اینترنت عمومی همچنان سیاست شبکهٔ محیط را رعایت می‌کنند. برای ساخت در Codex، گواهی عمومی رسمی پراکسی محیط به trust store تصویر افزوده شد؛ بررسی TLS خاموش نشد. این گواهی یا تنظیم ساخت ویژهٔ Cloud در بستهٔ دانلود قرار ندارد.
- خروجی واقعی آزمون قبلی بغداد از CSV خام همان موتور وارد SQLite شد: ۱۸ ردیف با شناسهٔ یکتا. واردکردن دوباره، تعداد را به ۳۶ افزایش نداد. این مرحله جست‌وجوی تازه‌ای به Google نفرستاد.
- توقف و شروع دوبارهٔ سرویس‌ها، ۱۸ سرنخ را حفظ کرد. مرورگر از داشبورد Docker خروجی XLSX با ۱۸ ردیف داده دریافت کرد. پشتیبان online SQLite نیز با integrity_check و شمارش ۱۸ ردیف بررسی شد.
- فقط `127.0.0.1:8090` برای برنامهٔ جدید منتشر می‌شود؛ موتور داشبورد هیچ port mapping ندارد. موتور اصلی قبلی جداگانه حفظ شده است.

## محدودیت‌ها و آزمون‌های لازم روی رایانهٔ شما

- Docker Desktop/WSL2، فایل‌های bat، بازشدن مرورگر، سازگاری نسخهٔ ویندوز ۱۰ و راه‌اندازی پس از reboot باید روی رایانهٔ واقعی بررسی شوند؛ محیط آزمون ویندوز در دسترس نبود.
- دسترسی به Google Maps، Nominatim و وب‌سایت هر کسب‌وکار به شبکهٔ شما وابسته است. استخراج زندهٔ بغداد قبلاً در همین محیط ۱۸ نتیجه داده بود؛ در این مرحلهٔ توسعه از همان خروجی استفاده شد و آزمون‌های UI کار خارجی جدیدی اجرا نکردند.
- نتیجهٔ Maps تضمین ارتباط صنفی یا قرارداشتن در شهر هدف نیست؛ در خروجی قبلی یک کسب‌وکار اربیل وجود داشت. کشور و شهر بانک، بازار مورد جست‌وجو هستند و نشانی واقعی باید بررسی شود.
- شمارندهٔ پیشرفت بر اساس ترکیب‌های پایان‌یافتهٔ شهر/کلیدواژه است؛ درصد پیشرفت داخلی مرورگر از موتور در دسترس نیست.
- ایمیل و پروفایل‌های عمومی اختیاری‌اند. دسترسی ناموفق وب‌سایت‌ها پوشش را کاهش می‌دهد؛ هیچ داده‌ای حدس زده نمی‌شود.
- یک نمونهٔ برنامه با یک worker پشتیبانی می‌شود؛ ورود چندکاربره، صفحه‌بندی، بار زیاد و یکپارچه‌سازی پیام‌رسان/ارسال پیام در این MVP وجود ندارد.
- خاموشی در فاصلهٔ ساخت کار موتور و ثبت شناسه می‌تواند کار بدون ارتباط باقی بگذارد. کار بلاتکلیف بیش از ۱۵ دقیقه متوقف و نیازمند بررسی می‌شود؛ تلاش خودکار برای دورزدن خطا انجام نمی‌شود.
- GitHub Actions اضافه شده، اما اجرای آن در خود GitHub تا زمان ارسال تغییرات آزمایش نشده است. تغییرات این نشست خودکار روی GitHub ارسال نشده‌اند.
